# GTA VI Command Center

Dashboard de prelanzamiento para ejecutar una estrategia de contenido desde el 22 de septiembre de 2026 hasta el lanzamiento de GTA VI el 19 de noviembre de 2026.

## Incluye
- Dashboard diario con checklist.
- Calendario de 59 días.
- Radar para separar confirmaciones, rumores y especulación.
- Centro de investigación con fuentes.
- Content Pipeline.
- Viral Vault GTA V → GTA VI.
- Watchlist de creadores.
- Registro de analíticas.
- Launch Mode del 12 al 19 de noviembre.
- Persistencia local mediante localStorage.

## Vercel
Es una aplicación estática. No requiere comando de build.
